Port a Raspberry Pi

Qué debemos reemplazar

Arranque

Eliminar MBR, BIOS e INT 13h. Crear una imagen ARM que el firmware de la Raspberry pueda cargar.

CPU

Reescribir el ensamblador x86: pila, entrada, cambio de contexto, excepciones y registros.

Pantalla

Reemplazar 0xB8000 por UART o framebuffer y dibujar caracteres como píxeles.

Entrada

Reemplazar puerto 0x60 y scancodes PS/2 por UART o un driver USB HID.

Interrupciones

Sustituir IDT/PIC 8259 por vectores de excepción ARM y el controlador de interrupciones del SoC.

Temporizador

Programar el timer del SoC para reloj, espera y planificación.

La solución: una HAL

Separar las políticas del kernel de los detalles de cada placa.

kernel común ├── procesos / scheduler ├── memoria / semáforos ├── filesystem / aplicaciones └── HAL ├── hal_x86.c → VGA, PIC, PS/2, puertos └── hal_rpi.c → UART, timer, IRQ, framebuffer
Primera Raspberry viable

Empezar sin HDMI ni USB

Para reducir drásticamente la complejidad, la primera versión debería usar una consola serie.

1. Arranque mínimo ARM

Inicializar CPU y pila; llamar a kmain().

2. UART como pantalla y teclado

Enviar y recibir caracteres por un adaptador USB–TTL.

3. Timer e interrupciones

Recuperar el reloj y luego la planificación.

4. Framebuffer

Agregar salida HDMI cuando la base sea estable.

5. USB

Dejar el teclado USB para una etapa avanzada.

Raspberry Pi ↔ USB–TTL ↔ PC

La terminal del PC actúa inicialmente como monitor y teclado.

Estructura propuesta

Organizar el código para dos arquitecturas

toy-os/ ├── kernel/ # código común en C │ ├── scheduler.c │ ├── semaforo.c │ ├── kmalloc.c │ ├── fs.c │ └── aplicaciones/ ├── arch/ │ ├── x86/ │ │ ├── boot.asm │ │ ├── idt.c │ │ ├── pic.c │ │ └── video_vga.c │ └── arm-rpi/ │ ├── start.S │ ├── vectors.S │ ├── uart.c │ ├── timer.c │ └── framebuffer.c ├── include/hal.h └── Makefile

El mismo kmain() llama a funciones abstractas: hal_putchar(), hal_getchar(), hal_timer_init().

Ejemplo de abstracción

Una función, dos implementaciones

Interfaz común

void hal_putchar(char c); char hal_getchar(void); void hal_timer_init(void);

x86

void hal_putchar(char c) { /* escribir en 0xB8000 */ }

Raspberry

void hal_putchar(char c) { /* enviar por UART */ }

El shell y los juegos llaman a hal_putchar(); no necesitan saber qué placa existe debajo.
